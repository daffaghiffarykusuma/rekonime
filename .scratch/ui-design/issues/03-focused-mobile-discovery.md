# 03: Make the Discovery homepage compact and focused

**What to build:** Help visitors reach a compact set of useful picks quickly, with supporting browsing available below the main journey.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The initial landing uses a short introduction and compact optional Viewing Intent choices before useful picks; immediate selection and the active summary remain functional.
- [ ] Mobile covers are shorter while titles, supported fit explanations, honest episode information, details access, and primary actions remain readable and operable.
- [ ] Up to three initial picks, Show more picks, goal suggestions versus alternatives, Planned confirmation, Session Dismissal, lasting feedback, and Undo remain intact.
- [ ] Seasonal picks, trending, genre exploration, and the catalog remain on the homepage under a quieter Browse anime area below the main picks; search and existing navigation targets remain accessible.
- [ ] Existing palette, typography, themes, recommendation rules, and rating disclosure hierarchy are preserved.
- [ ] Browser tests verify visible hierarchy and the discovery-to-selection journey at the approved seam, with a recorded failing-before/passing-after cycle for changed behavior.
- [ ] Desktop/mobile inspection covers fresh/returning visits, active/no goal, long titles, unknown data, expanded evidence, keyboard use, and increased text size; record dimensions chosen through inspection and affected check results.

## Context

Parent: [Mobile Discovery UI specification](../../../docs/ui-design-spec.md). Coordinate shared homepage edits with other slices, but they are not prerequisites. Record implementation commit and actual validation evidence when closing.
